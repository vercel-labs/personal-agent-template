# Build Skill

## Purpose
Turn a product request into a complete, maintainable implementation.

## Trigger
Use for new features, pages, workflows, integrations, or end-to-end product changes.

## Workflow
1. Inspect repository structure, package scripts, routes, components, APIs, and conventions.
2. Translate the request into acceptance criteria and identify affected layers.
3. Design the smallest coherent architecture before coding.
4. Implement the feature end-to-end instead of stopping at a visual mock.
5. Add loading, empty, error, success, and responsive states where relevant.
6. Validate with typecheck, lint, tests, and production build.
7. Report exactly what changed and what remains unverified.

## Output
A working implementation, validation evidence, and a concise change summary.
