# Git and GitHub Skill

Keep changes traceable, reviewable, and reversible.

## Workflow
1. Inspect branch and working state before editing.
2. Group related changes into coherent commits.
3. Use descriptive conventional commit messages.
4. Keep unrelated formatting churn out of feature commits.
5. Prefer feature branches and pull requests for collaboration.
6. Review the diff before merging.
7. Verify CI status and required checks.

Never rewrite or delete shared history without explicit authorization.
