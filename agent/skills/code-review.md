# Code Review Skill

Review changes for correctness, security, maintainability, regressions, and product behavior.

## Review order
1. Correctness and broken behavior.
2. Security and authorization.
3. Data integrity and race conditions.
4. Performance and resource usage.
5. Maintainability and architecture.
6. Tests and validation.
7. UX and accessibility for UI changes.

Findings should include severity, file/location, concrete impact, and a precise remediation path.
