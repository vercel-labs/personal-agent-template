# Design Skill

## Purpose
Create production-quality interfaces with deliberate hierarchy, spacing, typography, interaction states, and responsive behavior.

## Trigger
Use for non-trivial UI, redesigns, dashboards, landing pages, design systems, or product surfaces.

## Workflow
1. Establish product goal, audience, primary action, hierarchy, and visual personality.
2. Explore a distinct design direction instead of defaulting to generic AI UI.
3. Define layout, type scale, spacing, color roles, borders, radii, elevation, and motion.
4. Design desktop, tablet, and mobile states.
5. Include hover, focus, active, disabled, loading, empty, error, and success states.
6. Implement with reusable components and tokens.
7. Perform visual QA at relevant widths.

## Quality bar
The result must work as a product, not merely look good as a screenshot.
