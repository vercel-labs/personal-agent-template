# Frontend Engineering Skill

Build robust client interfaces with accessible, responsive, maintainable components.

## Workflow
1. Identify framework, routing, state, data fetching, styling, and component conventions.
2. Keep components focused and reusable.
3. Prefer semantic HTML and progressive enhancement.
4. Handle async states explicitly.
5. Avoid unnecessary global state and duplicated logic.
6. Test critical interactions and responsive layouts.
7. Run typecheck, lint, tests, and build.

## Checks
Keyboard navigation, focus visibility, mobile overflow, loading/error states, hydration/SSR correctness, and network failure behavior.
