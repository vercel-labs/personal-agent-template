# Performance Skill

Keep product interactions fast and resource-efficient.

## Workflow
1. Measure before optimizing.
2. Identify the largest user-visible bottleneck.
3. Reduce unnecessary JavaScript, rendering, network requests, and payload size.
4. Use caching and memoization only when justified.
5. Optimize images and fonts.
6. Protect server and database hot paths.
7. Re-measure after the change.

Never trade correctness for an unmeasured micro-optimization.
