# WebSandBox Agent Skills

Reusable skill library for WebSandBox agents.

## Groups
- **Build:** implementation, debugging, refactoring, orchestration.
- **Design:** product UI, responsive UX, accessibility.
- **Engineering:** frontend, backend, APIs, databases, performance, security.
- **Delivery:** testing, code review, Git/GitHub, CI/CD, DevOps, documentation.
- **Research:** evidence-driven technical investigation.

## Global rules
1. Inspect the repository before changing code.
2. Reuse existing architecture and conventions.
3. Make the smallest coherent change that completes the task.
4. Validate with typecheck, lint, tests, and build when available.
5. For UI work, validate responsive states and visual hierarchy.
6. Never claim a runtime, deployment, integration, or test is working unless verified.
7. Prefer reversible changes and clear commits.
