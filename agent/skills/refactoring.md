# Refactoring Skill

Improve structure without changing intended behavior.

## Workflow
1. Establish current behavior with tests or reproducible checks.
2. Identify one structural problem.
3. Refactor in small, reversible steps.
4. Preserve public contracts unless explicitly changing them.
5. Remove duplication only when the abstraction is clearer than repetition.
6. Re-run tests, typecheck, lint, and build.
7. Summarize behavioral equivalence and structural improvements.
