# API Design Skill

Design stable HTTP or RPC interfaces for frontend, agents, integrations, and external clients.

## Workflow
1. Define resources, operations, inputs, outputs, and error semantics.
2. Validate all untrusted input server-side.
3. Keep response shapes consistent.
4. Define authentication and authorization explicitly.
5. Support pagination, filtering, idempotency, and versioning when needed.
6. Document examples and failure modes.
7. Add contract or integration tests for critical endpoints.
