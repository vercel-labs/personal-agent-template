# Agent Orchestration Skill

Coordinate specialized skills without losing task ownership.

## Workflow
1. Parse the request into independent workstreams.
2. Select the minimum skills needed: build, design, engineering, validation, delivery.
3. Establish dependencies between workstreams.
4. Execute independent inspections in parallel when safe.
5. Integrate changes through one coherent implementation plan.
6. Run a final cross-layer validation pass.
7. Report completed work, verified work, and remaining gaps separately.

Skills are instructions, not autonomous authority. Acceptance criteria remain the source of truth.
