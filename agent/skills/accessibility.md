# Accessibility Skill

Make interfaces usable with keyboard, assistive technology, varied contrast needs, and different input methods.

## Checklist
- semantic landmarks and headings
- labels for controls and fields
- keyboard operation for every interactive control
- visible focus states
- logical focus order
- dialog focus management
- meaningful accessible names
- sufficient contrast
- reduced-motion support
- errors associated with inputs
- no information conveyed by color alone

Validate desktop and mobile states.
