# DevOps Skill

Operate applications reliably across development, staging, and production.

## Workflow
1. Identify environment boundaries and configuration sources.
2. Keep infrastructure configuration declarative where possible.
3. Separate secrets from source control.
4. Define health checks, logs, metrics, and rollback paths.
5. Prefer reversible deployment strategies.
6. Verify DNS, TLS, runtime, and dependencies after deployment.
7. Record operational assumptions and recovery steps.
