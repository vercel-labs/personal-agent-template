# Security Skill

Build secure-by-default applications and agent workflows.

## Checklist
- validate and constrain untrusted input
- enforce authorization server-side
- protect secrets and tokens
- prevent injection and unsafe command execution
- use safe redirects and URL handling
- protect CSRF-sensitive mutations
- avoid private data in logs and errors
- review filesystem and path traversal boundaries
- apply least privilege to integrations
- test abuse cases for new attack surfaces

Treat generated code as untrusted until reviewed.
