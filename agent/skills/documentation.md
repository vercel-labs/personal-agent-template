# Documentation Skill

Keep project knowledge synchronized with implementation.

## Workflow
1. Document user-visible behavior and important architecture.
2. Prefer concise examples over vague prose.
3. Update docs in the same change as behavior changes.
4. Record environment variables and setup prerequisites.
5. Document failure modes and troubleshooting.
6. Remove stale instructions when they become incorrect.

Documentation is part of the feature, not a postscript.
